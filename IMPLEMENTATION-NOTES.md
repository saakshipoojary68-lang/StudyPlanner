# StudyPlanner — Responsive CSS implementation

## What was updated
- Expanded `:root` design tokens for brand colors, typography, spacing, radii, shadows, and motion.
- Preserved the existing StudyPlanner layout and JavaScript functionality.
- Added keyboard-visible focus states and reduced-motion support.
- Added responsive refinements for compact laptops, tablets, phones, and 320px-wide screens.
- Added overflow safeguards to help prevent horizontal scrolling on small viewports.
- Kept the existing light/dark theme variables and made the dark color scheme explicit.

## Files
- `index.html` — existing application markup
- `style.css` — design tokens, component styles, and responsive breakpoints
- `script.js` — existing task planner behavior

## Suggested responsive proof screenshots
Capture the site at these viewport widths:
- Mobile: 320px or 375px
- Tablet: 768px
- Desktop: 1440px

Check that the task form, calendar, statistics, timer, and task list fit without horizontal scrolling.
